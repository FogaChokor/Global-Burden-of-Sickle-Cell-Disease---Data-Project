Global Burden of Sickle Cell Disease - Data Project
A three-phase epidemiological analysis of Sickle Cell Disease (SCD) burden across 204 countries and geographic regions from 2000 to 2021, using the IHME Global Burden of Disease (GBD) 2021 dataset.

Project Overview
Sickle Cell Disease is one of the most prevalent genetic conditions in the world, yet it remains chronically underfunded and under-analysed relative to its impact. This project builds a complete data analysis pipeline. From five raw CSV files to an interactive dashboard to quantify the global burden of SCD, identify regional and country-level patterns, and spotlight Nigeria as the country with the highest absolute SCD burden worldwide.

Pipeline:
Phase 1 - Excel: Data import, verification, exploration, aggregation, pivot tables, charts, and dashboard.
Phase 2 - Python: Full EDA, cross-file validation, genotype-level analysis, and master DataFrame export.
Phase 3 - Power BI: Four-page interactive dashboard.

Data Source
Dataset: IHME GBD 2021 Sickle Cell Disease Birth Incidence, Prevalence, and Mortality 2000 to 2021.
